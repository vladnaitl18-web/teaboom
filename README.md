# Карточка товара Teaboom.ru — «Ананасовый улун»

Тестовое задание: верхняя часть карточки товара интернет-магазина
[Teaboom.ru](https://teaboom.ru/product/ananasovij-ulun).

Стек: HTML5, SCSS, JavaScript без фреймворков и библиотек. Сетка — CSS Grid и Flexbox.

- `index.html` — **карточка товара «Ананасовый улун»** (само задание);
- `home.html` — главная страница магазина в той же стилистике (сверх задания).

## Запуск

Сборка не обязательна: скомпилированный `css/main.css` лежит в репозитории.

1. Открыть `index.html` в браузере.

Либо через локальный сервер:

```bash
npx serve .
```

### Правка стилей

```bash
npm install
npm run build   # scss/main.scss -> css/main.css
npm run watch   # пересборка при изменениях
```

## Структура

```text
index.html          карточка товара (тестовое задание)
home.html           главная страница (сверх задания)
scss/
  _tokens.scss      брейкпоинты, миксины, CSS-переменные (цвета, шрифты)
  _base.scss        сброс, базовая типографика, утилиты
  _layout.scss      шапка, навигация, хлебные крошки, подвал
  _product.scss     сетка карточки, изображение, заголовок, описание
  _purchase.scss    выбор фасовки, цена, кнопка
  _home.scss        блоки главной: баннер, преимущества, категории, товары
  main.scss         точка входа
css/main.css        скомпилированные стили
js/product.js       переключение фасовок, состояние кнопки
js/cart.js          счётчик корзины в шапке, кнопки «В корзину» на главной
img/                изображения товаров и категорий, логотип
```

## Что сделано

- **Фасовки** — группа радиокнопок в `fieldset`: работает с клавиатуры (Tab, стрелки)
  и читается скринридером без дополнительных ARIA-ролей.
- **Данные фасовок** хранятся в `data-`атрибутах радиокнопок, JS только читает их и
  обновляет артикул, цену, старую цену, процент скидки, выгоду и цену за 100 г. Стартовое
  состояние прописано в HTML, поэтому без JS страница не пустая.
- **Старая цена и бейдж скидки** скрываются автоматически, если у фасовки нет
  `data-old-price` или она не больше актуальной цены.
- **Кнопка «В корзину»** — состояния: обычное, hover (инверсия цветов, как у
  контролов корзины на Teaboom), active, focus-visible и «Добавлено» после клика.
  Реальная корзина не подключена: клик только увеличивает счётчик в шапке
  (хранится в `sessionStorage`, поэтому сохраняется при переходе между страницами).
- **Изображение** — `picture` с WebP и JPEG-фолбэком, `srcset`/`sizes`,
  заданные `width`/`height` (без сдвига макета при загрузке).

## Адаптивность

Mobile first, два брейкпоинта: `640px` и `1024px`.

| Ширина | Раскладка |
| --- | --- |
| 375 px | Одна колонка: заголовок → фото → фасовки 2×2 → цена → кнопка на всю ширину → описание → заваривание |
| 768 px | Две колонки (фото / заголовок и покупка), описание и заваривание на всю ширину ниже |
| 1440 px | Слева фото 540 px и параметры заваривания, справа заголовок, покупка и описание; фасовки в один ряд |

Проверено на ширинах 320, 375, 768 и 1440 px — горизонтальной прокрутки нет.

## Главная страница

Собрана из блоков действующей главной Teaboom.ru: шапка с навигацией, баннер,
преимущества, категории, «Рекомендуем», текст о магазине, подвал с контактами.
Товары, цены, категории и контакты взяты с сайта; ссылки ведут на настоящие разделы
teaboom.ru. Баннер ведёт на карточку «Ананасового улуна».

## Стилистика

Основа взята с действующего сайта: шрифты Open Sans и Oswald, фирменный жёлтый
`#f5d730`, жёлтая полоса навигации, красная цена со скидкой, инверсия тёмный/жёлтый в
активных состояниях. Графитовый `#202020` заменён на чайно-зелёный `#43895f`, в акцентах — светлый лаймовый `#e6efc6` их кнопок корзины. Поверх добавлена «чайная» подача: фон цвета рисовой бумаги,
деревянный поднос-чабань под фотографией, жёлтая полоса с китайским меандром в шапке,
нефритовый акцент и киноварная печать 茶. Всё декоративное сделано на CSS, без
дополнительных картинок.

Изображения, логотип и тексты — с сайта Teaboom.ru.
